Personal Expense Tracker
Project Description A Java application for managing personal expenses.

Features:
1-Add expenses.
2-Categorize expenses (Food, Shopping, Transport).
3-Calculate total expenses.
4-Calculate expenses by category.
5-View expense reports.
6-Export reports to CSV files.

Technologies Used:
1-Java
2-NetBeans 
3-CSV Files

Project Files:
1-Main.java
2-Expense.java
3-ExpenseManager.java
4-ExpenseChart.java
5-ChartTest.java
6-Reportable.java

Data File:
-expenses.csv

 How to Run
Run the Main.java file using NetBeans.
